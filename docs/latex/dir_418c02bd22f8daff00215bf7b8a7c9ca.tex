This project was developed for the {\bfseries{FP (Fundamentals of Programming)}} course at {\bfseries{Instituto Superior Técnico (IST)}}. It implements a fully functional Scrabble game in Python, allowing matches between human players and AI agents with different difficulty levels.\hypertarget{dir_418c02bd22f8daff00215bf7b8a7c9ca_autotoc_md4}{}\doxysubsubsection{\texorpdfstring{Key Objectives}{Key Objectives}}\label{dir_418c02bd22f8daff00215bf7b8a7c9ca_autotoc_md4}

\begin{DoxyItemize}
\item Implement Abstract Data Types (TADs) to represent game elements (Board, Player, Vocabulary).
\item Develop a robust game engine capable of validating moves according to Scrabble rules.
\item Design AI agents with varying strategies (Easy, Medium, Hard) using pattern matching and scoring heuristics.
\end{DoxyItemize}\hypertarget{dir_418c02bd22f8daff00215bf7b8a7c9ca_autotoc_md5}{}\doxysubsubsection{\texorpdfstring{Features}{Features}}\label{dir_418c02bd22f8daff00215bf7b8a7c9ca_autotoc_md5}

\begin{DoxyItemize}
\item {\bfseries{Data-\/\+Driven Vocabulary}}:\+ Efficient word lookups and scoring using optimized dictionary structures.
\item {\bfseries{AI Agents}}:\+ Automated players that simulate different skill levels by adjusting their search breadth and scoring priorities.
\item {\bfseries{Interactive Gameplay}}:\+ A command-\/line interface for human players to manage their letters, swap tiles, and place words on the 15x15 board.
\end{DoxyItemize}

\item Desenvolver um motor de jogo robusto capaz de validar jogadas de acordo com as regras oficiais.
